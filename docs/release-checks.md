## Current acceptance boundary

The initial actual Gemini text baseline passed all three expected conclusions and
exact returned quotations, but missed one labeled context quotation. The generic
context policy is now versioned `grounded-evidence-v2`; it requests materially
relevant earlier estimates without turning forecasts into contradictions.
Its live effect is unverified, rather than assumed from a prompt change.

New one-request PDF and text diagnostics both returned HTTP503, with sanitized
numeric status retained. The source facts were present in both text and extracted
PDF passages; these failures do not establish parser loss. The earlier historical
failures did not retain status, so their cause remains unknown. The session stopped
after two service failures without resetting old reports or substituting models.

[Draft quality gates](live-quality-gates.json) describe development prerequisites
before freezing a held-out run. They are not a passed gate or calibrated acceptance
claim. Local lexical vectors make no hosted embedding request and do not establish
semantic-embedding quality. Additional providers remain unverified under the
current exact-model testing restriction. [Live validation](live-validation.md)
records all measured limits and stopped sessions.
