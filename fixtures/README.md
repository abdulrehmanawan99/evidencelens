# Sample sources

These four reports are original synthetic text created for EvidenceLens. Harbor Transit and the numbers are fictitious; the content does not describe an actual organization or contain user data.

The canonical fixture definitions and supported claims are in `backend/app/fixtures.py`. These `.txt` copies contain the same bytes and can be uploaded manually to an empty collection. No outside source documents, recordings, or third-party copyrighted text were used.

The final operations and board reports intentionally disagree. The preliminary estimate has different evidentiary status, and the staff memo lacks quantitative support. These distinctions form the three predefined fixture scenarios; they are not measured live-model results.

The PDF versions in pdf/ are deterministic original renderings generated by scripts/generate-pdf-fixtures.py. two-page.pdf is a separate navigation fixture. evaluation.json adds independently labeled development and new-source held-out cases; the latter are reserved for live runs. ReportLab is a development-only dependency. No OCR or external copyrighted PDF corpus is bundled.
